# ショボン（Shobon）

**ショボン**は、8種類の顔文字だけでプログラムを書ける、[Brainfuck](https://en.wikipedia.org/wiki/Brainfuck) 系の難解プログラミング言語（esolang）です。

Brainfuckの8命令をそれぞれ顔文字に置き換えています。Python製のインタプリタで実行でき、Brainfuckのソースコードをショボンに変換するツールも付属しています。

![](shobon.png)
## 必要な環境

- Python 3
- UTF-8で保存できるテキストエディタ

外部ライブラリのインストールは不要です。

## インストール

リポジトリをクローンします。

```bash
git clone https://github.com/sabaholic1974/shobon.git
cd shobon
```


以下のファイルを同じディレクトリに配置します。

```text
shobon/
├── shobon.py          # ショボンのインタプリタ
├── bf_to_shobon.py    # Brainfuck → ショボン変換ツール
├── hello.shobon       # hello world表示サンプル
└── README.md
```

## 使い方

### 1. ショボンのプログラムを実行する

UTF-8のテキストファイル（例：`echo.shobon`）を作成し、以下のコードを保存します。

```text
(´･ω・ `)(´･ω･｀)
```

これは標準入力から1バイトを読み取り、その1バイトを出力するプログラムです（Brainfuckの `,.` に相当）。

実行例（macOS / Linux）：

```bash
printf 'A' | python shobon.py echo.shobon
```

実行例（Windows）：

```powershell
echo A | python shobon.py echo.shobon
```

出力：

```text
A
```

基本的な実行形式は次のとおりです。

```bash
python shobon.py <プログラムファイル>
```

入力ファイルを渡すこともできます。

```bash
python shobon.py echo.shobon < input.bin > output.bin
```

### 2. Brainfuckのコードをショボンに変換する

`hello.bf` などのBrainfuckソースを用意します。例えば、次のプログラムは `Hello World!` と改行を出力します。

```brainfuck
++++++++++[>+++++++>++++++++++>+++>+<<<<-]
>++.>+.+++++++..+++.>++.<<+++++++++++++++.>.+++.------.--------.>+.>.
```

以下のコマンドで変換できます。

```bash
python bf_to_shobon.py hello.bf hello.shobon
```

変換したファイルを実行します（macOS / Linux）：

```bash
python shobon.py hello.shobon
```

出力：

```text
Hello World!
```

変換結果をファイルではなく標準出力へ表示することもできます。

```bash
python bf_to_shobon.py hello.bf
```

リダイレクトによる保存にも対応しています。

```bash
python bf_to_shobon.py hello.bf > hello.shobon
```

変換ツールはBrainfuckの8命令以外の文字を読み飛ばし、命令に対応する顔文字を順番に連結して出力します。

## 言語仕様

### 命令一覧

ショボンの命令は、以下の**8種類の顔文字**だけです。

| Brainfuck | ショボン | 動作 |
|:---:|---|---|
| `>` | `(´・ω・｀)` | データポインタを右に1セル移動 |
| `<` | ``(´･ω・`)`` | データポインタを左に1セル移動 |
| `+` | ``(´・ω･`)`` | 現在のセルの値を1増やす |
| `-` | ``(´・ω・`)`` | 現在のセルの値を1減らす |
| `.` | `(´･ω･｀)` | 現在のセルの値を1バイト出力 |
| `,` | ``(´･ω・ `)`` | 標準入力から1バイト読み込み、現在のセルに格納 |
| `[` | ``( ´･ω･`)`` | 現在のセルが0なら、対応する `]` の次へ移動 |
| `]` | ``(´･ω･`)`` | 現在のセルが0でなければ、対応する `[` の次へ移動 |

### 顔文字の表記について

**顔文字は表のとおりに正確に記述してください。** 見た目のよく似た文字や空白の有無も区別されます。

- `,` に対応する ``(´･ω・ `)`` は、`・` と `` ` `` の間に**半角スペース1つ**があります。
- `[` に対応する ``( ´･ω･`)`` は、`(` の直後に**半角スペース1つ**があります。
- `･`（半角中黒）と `・`（全角中黒）は別の文字です。
- `` ` ``（半角バッククォート）と `｀`（全角の記号）は別の文字です。

ソースファイルは**UTF-8**で保存してください。

### メモリと実行モデル

- メモリは、初期値がすべて `0` の8ビットセルの列です。
- 初期状態では1セルが用意され、ポインタは先頭セル（位置 `0`）を指します。
- 右方向への移動に応じてメモリは自動的に拡張されます。
- 左端（位置 `0`）より左へ移動するとエラーになります。
- 各セルの値は `0` 〜 `255` です。`255 + 1` は `0`、`0 - 1` は `255` に循環します。
- `[` と `]` は対応するペアが必要です。対応が取れない場合は構文エラーになります。

### 入出力

- 入力命令は標準入力から1バイトずつ読み込みます。
- 入力がEOF（ファイル終端）に達した場合、現在のセルには `0` を格納します。
- 出力命令は現在のセルの値を、そのまま**1バイト**として標準出力に書き込みます。
- 文字コードへの変換は自動では行いません。文字列を表示する場合は、プログラム側でASCIIやUTF-8のバイト列を生成する必要があります。

### コメントと無効な文字

インタプリタはソースを左から右へ読み、定義された8種類の顔文字を命令として認識します。それ以外の文字（改行やコメント文字など）は無視します。

そのため、**未定義の顔文字を書いても必ずしもエラーにはならず、無視される**点に注意してください。意図しない動作を避けるため、プログラム本体には定義済みの顔文字だけを使用することを推奨します。

## ファイル形式

ショボンのソースコードの拡張子は任意ですが、このREADMEでは `.shobon` を使用します。

| 拡張子 | 用途 |
|---|---|
| `.shobon` | ショボンのプログラム（UTF-8テキスト） |
| `.bf` | Brainfuckのプログラム |

## Brainfuckとの互換性

ショボンはBrainfuckの8命令と1対1で対応しています。ただし、Brainfuckは実装によってセル幅・テープの端・EOFの扱いが異なる場合があります。本実装では、**8ビットセル・左端固定・EOF時は0**というルールを採用しています。
